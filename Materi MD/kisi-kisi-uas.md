Kisi-kisi Ujian Mata Kuliah Teknologi Pengolahan Data:

    hadoop: pemrosesan terdistribusi, materi-materi penting dari buku textbook.
    data ware house: konsep utama, perbedaan arsitektur-arsitektur DWH, perbedaan data mart dan data ware house, contoh-contoh rancangan model data, slowly changing dimensions.
    etl: konsep utama, perbedaan etl dengan elt, alur kerja etl.
    pengenalan hadoop: konsep, komponen utama, bagaimana kerja, single node, jenis-jenis node dan perbedaannya. konsep dan pengertian HDFS dan komponennya .
    mapreduce : Konsep, Penggunaan, contoh penggunaan mapreduce, cara kerja mapreduce secara detail.
    tools dari sqoop sampai spark: Spesialisasi aplikasi(yang membedakan tools tersebut dengan tools lain), fungsi utama, cara kerja(secara konseptual tanpa kode)
